A Discord bot for the Sea Worthy clan, built with discord.py and a plugin-based architecture for easy extensibility.

Features

Slash command support via discord.py app commands
Plugin system — add or remove commands by dropping .py files into the plugins/ folder
Live plugin reloading without restarting the bot
Role-gated reload command
CSV logging utilities

Requirements

Python 3.10+
discord.py 2.0+
